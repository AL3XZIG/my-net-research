# E5 — Концентрация шлюзов у одного оператора

**Цель:** оценить влияние увеличения числа шлюзов, принадлежащих одному оператору, на устойчивость межсетевой связи.

**Независимая переменная:** количество шлюзов из пяти, назначенных общему оператору (от 0 до 5).

**Фиксируемые параметры:** пять шлюзов; вероятность независимого отказа шлюза 0,05; вероятность отказа оператора 0,1.

**Метод:** для каждого уровня концентрации выполнить одинаковое число испытаний. Сравнить доступность и среднее число активных шлюзов.

**Интерпретация:** особое внимание уделить различию между количеством шлюзов и количеством независимых доменов отказа.

**Файл данных:** `results/raw-data/e5.csv`.
