# Протоколы экспериментов

Эксперименты E1–E5 выполняются на одной и той же графовой модели. В каждом запуске фиксируются число испытаний, seed, вероятности отказов и топология. Результаты записываются в CSV в `results/raw-data/`.

| Эксперимент | Проверяемый фактор | Основная метрика |
|---|---|---|
| E1 | Число параллельных шлюзов | Доступность связи |
| E2 | Один шлюз против альтернативных шлюзов | Доступность после отказов |
| E3 | Топология: цепочка и альтернативные пути | Связность крайних сетей |
| E4 | Независимые операторы против общего оператора | Доступность при общем отказе |
| E5 | Доля шлюзов одного оператора | Зависимость от общей точки отказа |

Перед интерпретацией результатов проверьте, что сравниваемые сценарии отличаются только исследуемым фактором либо что все остальные различия явно указаны.
