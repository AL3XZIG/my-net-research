# E2 — Отказ центрального шлюза

**Цель:** сравнить архитектуру с единственным шлюзом и архитектуру с двумя параллельными шлюзами от разных операторов.

**Независимая переменная:** число альтернативных шлюзов.

**Фиксируемые параметры:** вероятность отказа шлюза 0,1; вероятность общего отказа оператора 0; одинаковое число испытаний.

**Метод:** выполнить Монте-Карло для сценариев `single` и `parallel`, сравнить оценку доступности.

**Ограничение:** это вероятностное сравнение сценариев, а не моделирование конкретной реальной аварии. Для демонстрации единичного отказа дополнительно можно показать детерминированный пример отключения одного ребра.

**Файл данных:** `results/raw-data/e2.csv`.
