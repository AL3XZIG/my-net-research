# Воспроизведение экспериментов

## Требования

- Python 3.10+
- Дополнительные пакеты для запуска модели не требуются.

## Запуск

Из корня репозитория:

```bash
python -m simulation.src.run_experiments --trials 10000 --seed 42
python -m unittest discover -s simulation/tests -v
```

## Архивирование результата

После запуска сохраните:
1. CSV-файлы из `results/raw-data/`;
2. параметры командной строки;
3. commit hash исходного кода;
4. дату запуска и версию Python;
5. описание любых ручных изменений или исключённых запусков.

Для повторного эксперимента используйте тот же seed и ту же версию кода. Для оценки устойчивости результата дополнительно проведите несколько запусков с разными seed.
