# Результаты

Здесь размещаются обработанные таблицы, графики и краткие интерпретации.

- `raw-data/` — исходные CSV, созданные скриптом экспериментов.
- `graphs/` — графики, построенные по проверенным данным.
- `tables/` — сводные таблицы и расчёты.

Не добавляйте вымышленные или демонстрационные числа под видом экспериментальных результатов. Для каждого графика указывайте эксперимент, параметры запуска, число испытаний и seed.
