# Исходные данные

CSV-файлы E1–E5 создаются командой:

```bash
python -m simulation.src.run_experiments --trials 10000 --seed 42
```

Файлы в этой директории являются результатом конкретного запуска. При повторном запуске с другими параметрами сохраняйте отдельную копию или фиксируйте параметры и commit в журнале экспериментов.
